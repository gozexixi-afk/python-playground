# python-playground

Python 学习记录 - 从零基础到 AI 应用开发

## 目录结构

```
basics/       - Python 基础练习（补课周 8/3-8/9）
  day01-syntax/             - [补课Day1前半] 语法迁移 + LeetCode
  day02-api/                - requests + JSON
  day03-types-decorators/   - [补课Day1] 类型提示 + 装饰器（前置补齐）
  day04-exceptions-files/   - [补课Day2] 异常处理 + 文件操作
  day05-fstring-dict/       - [补课Day3] f-string + 字典 + 列表推导式
  day06-07-llm-chat/        - [补课Day4] LLM API 终端聊天脚本 + Git
  day08-modules-packages/   - [补课Day5] 模块与包 + 项目重构（memo_mind）
  day09-10-fastapi/         - [补课Day6-7] FastAPI 基础（路由/参数/响应）

  easy/       - 简单题
  medium/     - 中等题

```
