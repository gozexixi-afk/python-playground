# python-playground

Python 学习记录 - 从零基础到 AI 应用开发

## 目录结构

```
basics/       - Python 基础练习（Week 1-2）
  day01-syntax/          - 语法迁移 + LeetCode
  day02-api/             - requests + JSON
  day03-types-decorators/ - 类型提示 + 装饰器
  day04-exceptions-files/ - 异常处理 + 文件操作
  day05-fstring-dict/     - f-string + 字典 + 列表推导式
  day06-07-llm-chat/      - LLM API 终端聊天脚本

leetcode/     - LeetCode 刷题记录
  easy/       - 简单题
  medium/     - 中等题

snippets/     - 实用代码片段和工具
```

## 学习路线

- Week 1-2: Python 基础语法 + LLM API 初探
- Week 3+: 转入 [MemoMind](https://github.com/gozexixi-afk/memo-mind) 项目开发

## 运行环境

- Python 3.13+
- pip + venv
